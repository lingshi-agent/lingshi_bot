# `lingshi setup`

Initialize `~/.lingshi/lingshi.json` and the agent workspace.

Related:

- Getting started: [Getting started](/start/getting-started)
- Wizard: [Onboarding](/start/onboarding)

## Examples

```bash
lingshi setup
lingshi setup --workspace ~/.lingshi/workspace
```

To run the wizard via setup:

```bash
lingshi setup --wizard
```
