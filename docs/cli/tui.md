# `lingshi tui`

Open the terminal UI connected to the Gateway.

Related:

- TUI guide: [TUI](/tui)

## Examples

```bash
lingshi tui
lingshi tui --url ws://127.0.0.1:18789 --token <token>
lingshi tui --session main --deliver
```
