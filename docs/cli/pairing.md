# `lingshi pairing`

Approve or inspect DM pairing requests (for channels that support pairing).

Related:

- Pairing flow: [Pairing](/start/pairing)

## Commands

```bash
lingshi pairing list whatsapp
lingshi pairing approve whatsapp <code> --notify
```
